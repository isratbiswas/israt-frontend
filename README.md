🚀 WA Landing Page
A modern, responsive landing page built using Next.js (App Router), TypeScript, and Tailwind CSS. This project follows a scalable and modular architecture, making it easy to maintain and extend.
Live Link: <a href="https://walandingpage.vercel.app/">WA_LANDING_PAGE</a>
📌 Features
⚡ Built with Next.js App Router
🎨 Styled using Tailwind CSS
📱 Fully responsive design
🧩 Modular component structure
🔄 Reusable UI components
🚀 Optimized for performance and SEO

⚙️ Installation
Clone the repository:
git clone https://github.com/your-username/wa-landing-page.git
cd wa-landing-page

Install dependencies:

npm install
# or
yarn install
▶️ Running the Project

Start the development server:

npm run dev

Open your browser:
http://localhost:3000

📦 Build for Production
npm run build
npm start

🧩 Component Architecture
layout/ → Global or structural components (e.g., loaders)
modules/ → Large sections of the landing page (Hero, Testimonials, etc.)
shared/ → Reusable UI elements (Navbar, Footer)

🎯 Best Practices Followed
Clean folder structure for scalability
Separation of concerns (UI vs layout vs modules)
Reusable and maintainable components
Consistent naming conventions
Type safety using TypeScript
